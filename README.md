# 📅 Telegram-бот для онлайн-записи клиентов

Бот, через который клиенты салона красоты, барбершопа, автосервиса или любого бизнеса с записью сами выбирают услугу и свободное время, а владелец сразу получает уведомление о новой записи.

> Демо-проект для портфолио. Название студии, адрес и цены вымышленные и меняются под любой бизнес в одном файле.

## Зачем это бизнесу

- клиенты записываются 24/7, без звонков и переписки в мессенджерах;
- администратор не тратит время на подбор свободного окна;
- нет «двойных» записей на одно время;
- владелец видит все записи на день одной командой.

## Возможности

**Для клиента**
- главное меню с кнопками: «Записаться», «Мои записи», «Контакты»;
- выбор услуги с ценой;
- выбор дня на неделю вперёд: выходные и полностью занятые дни скрыты;
- выбор времени: показываются только свободные и ещё не прошедшие слоты;
- ввод имени и телефона, телефон отправляется одной кнопкой;
- подтверждение записи с адресом и контактами;
- просмотр и отмена своих записей.

**Для владельца**
- мгновенное уведомление о каждой новой записи и отмене;
- список записей на сегодня и завтра: `/today`, `/tomorrow`.

**Надёжность**
- два клиента не могут занять одно время, даже если нажали одновременно (уникальный индекс в базе);
- кнопка «Назад» на каждом шаге, `/cancel` прерывает запись;
- проверка имени и номера телефона, экранирование пользовательского ввода.

## Технологии

- Python 3.9+
- [aiogram 3](https://docs.aiogram.dev/) — асинхронный фреймворк для Telegram-ботов
- SQLite — хранение записей, без отдельного сервера базы данных
- FSM (машина состояний) для пошагового диалога

## Настройка под бизнес

Всё в файле `config.py`, код менять не нужно:
- название, адрес, телефон, часы работы;
- список услуг и цены;
- начало и конец рабочего дня, длительность слота;
- выходные дни и на сколько дней вперёд открыта запись.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Установите зависимости:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
4. Скопируйте `.env.example` в `.env` и впишите токен и ID.
5. Запустите:
   ```bash
   python bot.py
   ```

## Структура

| Файл | Что внутри |
| --- | --- |
| `bot.py` | диалог с клиентом, меню, команды владельца |
| `db.py` | база записей и расчёт свободного времени |
| `config.py` | настройки бизнеса |
| `.env.example` | образец файла с токеном |

## Нужен такой бот для вашего бизнеса?
